# Enregistrements LMU

Les séances enregistrées par le plugin (interrupteur « Enregistrer » dans l'onglet Général ; fichiers dans
`Documents\Endurance Manager\Enregistrements` sur le PC). Chaque `.emrec` posé ici est rejoué par la CI à chaque PR
(`dotnet run --project tests/Replay -c Release -- rejouer <fichier>`).

Nommer le fichier : `circuit-voiture-seance.emrec` (ex. `le-mans-9x8-essais.emrec`).
