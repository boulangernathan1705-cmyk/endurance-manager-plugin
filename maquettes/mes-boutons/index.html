Rotary + Fn

Un seul rotary règle plusieurs choses. Le bouton Fn choisit lequel. Pas de nouvelle commande : le module écrit la combinaison dans le Control Mapper de SimHub, qui gère le Fn lui-même, vers les commandes TC, ABS, carto… déjà créées.

  1. Montrer ton rotary et ton Fn
    Tourne le rotary d'un cran de chaque côté, puis appuie sur Fn. Le module les reconnaît.
  2. Comment marche Fn
    Maintenu : sans Fn = réglage 1, Fn tenu = réglage 2.
  3. Ce que règle le rotary
Essai en direct

Retirer les touches FMT

Retire seulement ce que FMT a ajouté, dans LMU et le Control Mapper. Tes touches à toi restent. Sauvegarde faite avant.
